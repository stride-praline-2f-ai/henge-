# Henge IPA build

Prepared Henge source changes are supplied as a pinned patch with review and verification metadata. Builds target this repository's self-hosted macOS runner only. No Apple ROM or macOS image is included. Henge remains GPL-2.0; original source: https://github.com/Leviidev/Henge.

The runner is hosted inside Henge: keep Henge visible during a build. Background GPU capability reporting is not proof of working background VM execution.
